# 03 — Screens

ดู mockup ภาพจริงได้ที่ `mockups/all-screens.html` (เปิดในเบราว์เซอร์) เอกสารนี้อธิบาย state และพฤติกรรมที่ mockup แสดงไม่ได้

## Navigation graph

```
SignIn
└── TripList  (start destination เมื่อล็อกอินแล้ว)
    ├── CreateTrip
    ├── JoinTrip
    └── TripDetail/{tripId}          ← bottom nav 5 แท็บ
        ├── Overview
        ├── DayPlan
        │   └── ActivityEditor/{dayId}/{activityId?}
        ├── ExpenseList
        │   ├── ExpenseEditor/{expenseId?}
        │   └── ExpenseDetail/{expenseId}
        │       └── SlipViewer
        ├── Settlement
        │   └── PromptPayQr/{toMemberId}/{amount}
        └── Extras
            ├── Checklist
            └── PollList → PollEditor
    Settings (จาก TripList)
```

Deep link: `triptogether://join/{code}` และ `https://triptogether.app/join/{code}` (App Links)

## รายละเอียดแต่ละหน้า

### S01 SignIn
ปุ่มเดียว "เข้าสู่ระบบด้วย Google" ผ่าน Credential Manager
- ถ้าเข้ามาจาก deep link ให้เก็บ `pendingInviteCode` ไว้ แล้วพาไป JoinTrip ทันทีหลังล็อกอินสำเร็จ
- ครั้งแรกที่ล็อกอิน สร้าง `users/{uid}` แล้วพาไป Settings เพื่อกรอกพร้อมเพย์ (ข้ามได้)

### S02 TripList
- 2 กลุ่ม: "กำลังจะถึง" (endDate ≥ วันนี้) และ "จบแล้ว" เรียงจากใหม่ไปเก่า
- แต่ละการ์ดแสดง ชื่อ, ช่วงวันที่, avatar สมาชิกซ้อนกัน, และ badge ยอดที่ตัวเองยังค้างจ่าย (ถ้ามี)
- Empty state: "ยังไม่มีทริป" + ปุ่มสร้าง และปุ่มเข้าร่วมด้วยรหัส
- FAB → CreateTrip, ปุ่มรองที่ header → JoinTrip

### S03 CreateTrip
ฟอร์ม: ชื่อทริป (บังคับ), วันเริ่ม–วันจบ (date range picker, บังคับ), รูปปก (ข้ามได้)
- `endDate` ต้อง ≥ `startDate`, ช่วงยาวสุด 60 วัน
- เมื่อกดสร้าง: เขียน `trips/{id}` + `members/{ownerMemberId}` + `days/*` ทุกวัน + `inviteCodes/{code}` ใน **batch write เดียว**
- ถ้ารหัสเชิญชนกัน (โอกาสต่ำ) ให้สุ่มใหม่แล้ว retry สูงสุด 5 ครั้ง

### S04 JoinTrip
ช่องกรอกรหัส 6 หลัก (auto-uppercase, แสดงเป็น 6 ช่อง)
- อ่าน `inviteCodes/{code}` → ถ้าไม่พบหรือ `active = false` แสดง "ไม่พบรหัสนี้"
- แสดง preview ชื่อทริปให้ยืนยันก่อนเข้าจริง
- ถ้าเป็นสมาชิกอยู่แล้ว → พาเข้าทริปเลย ไม่สร้าง member ซ้ำ

### S05 Overview
- Header: ชื่อทริป, ช่วงวันที่, countdown ("อีก 21 วัน" / "วันที่ 2 ของทริป" / "จบแล้ว")
- การ์ดสมาชิก: avatar + ชื่อ + ปุ่ม "ชวนเพื่อน" (แชร์ sheet พร้อมข้อความและลิงก์)
- การ์ดสรุปเงินย่อ: ยอดใช้ไปทั้งทริป + ยอดคงเหลือของฉัน → แตะไป Settlement
- ช่องโน้ตรวมของทริป (แก้ได้ทุกคน)
- เจ้าของเห็นเมนู: แก้ไขทริป, ลบสมาชิก, ปิดรหัสเชิญ, เก็บเข้าคลัง

**แก้ช่วงวันที่:** ถ้าย่นวันให้เตือนว่ากิจกรรมในวันที่หายไปจะถูกลบ ต้องยืนยันก่อน ถ้าขยายวันให้สร้าง `days` เพิ่มโดยไม่แตะของเดิม

### S06 DayPlan
- แถบวันแนวนอนด้านบน เลื่อนได้ วันที่เลือกไฮไลต์ วันปัจจุบันมีจุดบอก
- Timeline แนวตั้ง เรียงตาม `startTime` (ที่ไม่มีเวลาไปอยู่ท้ายสุดเรียงตาม `sortOrder`)
- กิจกรรมแสดง: เวลา, ชื่อ, สถานที่ (แตะ → Maps intent), badge ไฟล์แนบ, badge โหวตถ้าผูกกับ poll
- Empty state ต่อวัน: "ยังไม่มีแผนวันนี้" + ปุ่มเพิ่ม
- Realtime: snapshot listener ต่อวันที่กำลังดู ไม่ใช่ทั้งทริป

### S07 ActivityEditor
ฟอร์ม: ชื่อ (บังคับ), เวลาเริ่ม/จบ, สถานที่ (ค้นด้วย Places Autocomplete หรือพิมพ์เอง), โน้ต, ไฟล์แนบ
- ปุ่มลบอยู่ล่างสุด ต้องยืนยัน

### S08 ExpenseList
- จัดกลุ่มตามวัน หัวข้อกลุ่มแสดงยอดรวมของวันนั้น
- แต่ละแถว: ไอคอนหมวด, ชื่อ, "จ่ายโดย X", ยอดรวม, และยอดของฉันในบิลนี้ (ตัวเล็กสีจาง)
- แถบกรองบนสุด: ทั้งหมด / อาหาร / ที่พัก / เดินทาง / อื่นๆ
- Header ติดบนสุด: ยอดรวมทริป + ยอดของฉัน
- FAB → ExpenseEditor

### S09 ExpenseEditor ⭐ หน้าที่สำคัญที่สุด
ดู `docs/04-money-logic.md` ประกอบ ห้าม implement โดยไม่อ่าน

- ฟิลด์: ชื่อ, หมวด, ยอดรวม, คนจ่าย, วันที่ (default = วันนี้ถ้าอยู่ในช่วงทริป), สลิป
- แถบเลือกโหมด 3 ปุ่ม: หารเท่า / ใส่เอง / ตามสัดส่วน
- รายชื่อสมาชิกพร้อม checkbox — คนที่ไม่ติ๊กไม่มี share (ไม่ใช่ share = 0)
- **โหมดหารเท่า:** ช่องยอดของแต่ละคนเป็น read-only คำนวณสดทุกครั้งที่ติ๊ก/ยอดรวมเปลี่ยน
- **โหมดใส่เอง:** ช่องยอดแก้ได้ + แถบสถานะด้านล่างอัปเดตทันที
  - ตรงพอดี → แถบเขียว "ครบแล้ว" ปุ่มบันทึกเปิด
  - ไม่ตรง → แถบแดง "ขาดอีก X" / "เกินไป X" **ปุ่มบันทึก disable**
  - ปุ่ม "เกลี่ยส่วนที่เหลือ" (disable เมื่อทุกคนกรอกครบ) และ "+ ค่าบริการ 10%"
- **โหมดตามสัดส่วน:** stepper +/− ตั้ง weight ต่อคน ช่องยอดคำนวณให้
- สลิป: ถ่ายด้วย CameraX หรือเลือกจากแกลเลอรี แนบได้หลายรูป กดค้างเพื่อลบ
- บันทึกแบบ optimistic — เขียนลง Firestore cache ทันที ใช้งานต่อได้แม้ไม่มีเน็ต

### S10 ExpenseDetail
- แสดงข้อมูลบิลครบ + รายการ share ต่อคน + รูปสลิป (แตะ → SlipViewer แบบ zoom/pan)
- ปุ่มแก้ไข/ลบ: แสดงเฉพาะเมื่อเป็นคนสร้างบิลหรือเป็นเจ้าของทริป
- แสดงเวลาสร้างและคนสร้าง

### S11 Settlement
- การ์ดสถิติ 2 ใบ: ยอดใช้ทั้งทริป, เฉลี่ยต่อคน
- ตารางยอดคงเหลือทุกคน (+ เขียว / − แดง)
- รายการโอนที่แนะนำ พร้อมปุ่ม "QR พร้อมเพย์" และ "โอนแล้ว"
  - ปุ่ม QR แสดงเฉพาะเมื่อผู้รับมี `promptpayId` ถ้าไม่มีให้แสดง "ยังไม่ได้ตั้งพร้อมเพย์"
  - กด "โอนแล้ว" → สร้าง `settlements` สถานะ `PENDING` → ผู้รับได้ push แล้วกดยืนยันเป็น `CONFIRMED`
- รายการที่ยืนยันแล้วยุบลงไปอยู่กลุ่ม "เคลียร์แล้ว" สีเขียว
- Empty state เมื่อทุกคนเคลียร์: "ทุกคนเคลียร์กันหมดแล้ว"

### S12 Checklist
- 2 แท็บ: ของส่วนกลาง / ของส่วนตัว
- ส่วนกลาง: ติ๊กแล้วทุกคนเห็นเหมือนกัน มอบหมายคนรับผิดชอบได้ (avatar ท้ายแถว)
- ส่วนตัว: แต่ละคนติ๊กของตัวเอง เห็นเฉพาะสถานะตัวเอง แต่รายการร่วมกัน
- เพิ่มรายการแบบ inline (พิมพ์แล้วกด enter ต่อได้เลย ไม่เด้ง dialog)

### S13 PollList / PollEditor
- สร้างคำถาม + ตัวเลือก 2–8 ข้อ เลือกได้ว่าโหวตหลายข้อได้ไหม
- แสดงผลเป็นแถบสัดส่วน + avatar คนที่โหวตแต่ละข้อ
- ผูกกับกิจกรรมในแผนได้ (optional `activityId`)
- เจ้าของโพลปิดโหวตได้

### S14 Settings
- โปรไฟล์: ชื่อที่แสดง, รูป, **เบอร์พร้อมเพย์** (validate 10 หลักหรือเลขบัตร 13 หลัก)
- การแจ้งเตือน: toggle แยกตามประเภท (บิลใหม่ / แผนเปลี่ยน / เรื่องเงิน)
- ออกจากระบบ, ลบบัญชี

## Cross-cutting

**Loading:** shimmer placeholder ไม่ใช่ spinner กลางจอ — Firestore มี cache อยู่แล้ว หน้าจอส่วนใหญ่ควรมีข้อมูลทันที

**Error:** snackbar พร้อมปุ่ม "ลองใหม่" สำหรับ error ที่ retry ได้ ส่วน validation error แสดงใต้ฟิลด์นั้น ๆ

**Offline:** แสดงแถบบาง ๆ ด้านบน "ออฟไลน์ — จะซิงก์เมื่อมีเน็ต" เมื่อ `NetworkMonitor` รายงานว่าไม่มีการเชื่อมต่อ ไม่ต้อง block UI

**Empty state:** ทุกลิสต์ต้องมี ข้อความ + ปุ่ม action ห้ามปล่อยจอว่าง

**ธีม:** รองรับ dark mode เต็มรูปแบบ ใช้ Material 3 dynamic color บน Android 12+ และ fallback palette ที่กำหนดเองบนรุ่นเก่ากว่า
